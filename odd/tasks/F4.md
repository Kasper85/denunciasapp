# F4 · app-detalle — Detalle y atender

- **Objetivo**: Pantalla de detalle para visualizar todos los campos de una denuncia por su ID, y permitir marcarla como atendida mediante PUT a la API, actualizando la UI en tiempo real y notificando cambios a la lista launcher con `RESULT_OK`.
- **Estado**: HECHA

## Checklist
- [x] F4-T1: `DetalleUiState` y `DetalleViewModel` con operaciones de carga por ID y atención (PUT), y pruebas unitarias completas.
- [x] F4-T2: Layout `activity_detalle.xml` con campos completos (ID, DNI, Tipo, Fecha, Dirección, Descripción, Badge de Estado), botón de atender y vistas de carga/error.
- [x] F4-T3: `DetalleActivity` con lectura de `EXTRA_ID`, observador de estados, botón "Atender" condicional al estado pendiente y retorno de `RESULT_OK` ante modificaciones.

## Criterios de aceptación
- Pruebas de `DetalleViewModelTest` verdes (carga exitosa, error 404, cambio de estado a 0 al atender).
- `.\gradlew.bat testDebugUnitTest assembleDebug` compila y pasa todas las pruebas (BUILD SUCCESSFUL in 18s).
- APK generado en `app/build/outputs/apk/debug/app-debug.apk`.
